# README screenshot

`public-demo.png` is a real Chromium screenshot of Bookmark-Page V2, captured on 2026-10-29 with the light theme, pink accent, gradient background and public demo data. All twelve entries use real favicons fetched from their websites and public HTTPS links. No home-lab data or credentials appear in the image.

The demo contains Canva, Cloudflare, Discord, Figma, Firefox, GitLab, Google, OpenStreetMap, Slack, Spotify, Trello and YouTube. Their favicons identify the corresponding services; they are not generated artwork. The previous generated banner has been removed at the user's request.
