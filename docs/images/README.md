# README screenshot

`public-demo.png` is a real Chromium screenshot of Bookmark-Page V2, captured on 2026-10-29 with the dark theme, pink accent, gradient background and an isolated public demo database. The demo contains 28 public websites, all with real favicons fetched from their websites and public HTTPS links. The image captures only the 1600 × 900 viewport; additional entries continue below the visible cards. No home-lab data or credentials appear in the image.

The demo includes Canva, Cloudflare, Discord, Figma, Firefox, GitLab, Google, OpenStreetMap, Slack, Spotify, Trello, YouTube and sixteen additional public services and open-source projects. Their favicons identify the corresponding services; they are not generated artwork. The previous generated banner has been removed at the user's request.
