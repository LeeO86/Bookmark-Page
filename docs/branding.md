# Default app icon

`app/public/branding/bookmark-page-icon.png` is the built-in banner logo. It has a transparent background and is shared by light and dark themes. An uploaded site logo takes precedence; removing that custom logo restores the bundled icon. No settings or database migration is needed for existing installations. The per-instance browser-tab favicon remains configurable separately.

Generated on 2026-10-29 using the built-in Imagegen tool at the user's request. The original alpha channel is preserved. This compact app icon replaces no user-uploaded content; the former generated README scenery banner was removed separately.

## Generation prompt

```text
Use case: logo-brand. Asset type: production app icon and compact header logo for Bookmark-Page, a modern bookmark and device portal. Create one polished, distinctive square app mark on a genuinely transparent background. Subject: a small fan of three bold interlocking bookmark ribbons, each with a clear V-shaped bookmark notch, suggesting saved links and organised tabs. Colourful pink/magenta, cyan/blue and warm amber accents, with crisp edges and subtle dimensional layering; clean modern software identity rather than an illustration. Center the mark with a compact silhouette and generous optical clarity at 40–64 pixels. Keep all meaningful forms within the middle 82% of the square. The colourful mark must remain clearly visible on both deep navy dark-mode backgrounds and white light-mode backgrounds. No text, letters, wordmark, photographic scenery, gradients extending across a backdrop, rounded-square background plate, watermark, border or mockup. Output a high-quality standalone PNG with real alpha transparency.
```
